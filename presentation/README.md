## 2. 结题答辩与现场实物演示建议（15 分钟）

在课程结题答辩展示中，建议按以下节奏结合实物完成 15 分钟汇报：

1. **项目定位与双板架构（约 3 分钟）**
   - 展示 Arduino UNO R4 WiFi（`node01`）与 ESP32-C3（`node02`）单 USB 线 `5V/GND` 串联供电的紧凑桌面形态，以及后端八容器双网段安全隔离拓扑。
2. **三大工程难点攻关（约 4 分钟）**
   - **感知与点阵协同**：SHT31 串口 9600 8N1 跨周期 CRLF 分帧状态机，以及解除 RA4M1 Port 0 `A0` 采样与 12×8 LED 点阵驱动 `PWPR` 寄存器锁冲突。
   - **安全通信与新鲜度门禁**：解决 Python 3.13 下 TLS 自签名 CA 的 SKI/AKI 扩展校验，建立验证器防重放水位与 HA 35 秒断流自动过期机制。
   - **空调红外控制路线演进**：分析开源库 `sendGree()` 140 边沿单段帧与格力原装遥控器 280 边沿双段长帧的差异，切换至 `learn1` 原始微秒脉冲学习、14 字段状态防呆比对与一次性挑战码回放。
3. **数据滤波、团队分工与预算（约 3 分钟）**
   - 展示 57.64 元高性价比硬件采购清单、六人三组（感知点阵组、红外通信组、平台与智能体组）协作分工，以及 HA 24 小时滚动历史保留 + 一维因果卡尔曼滤波平滑效果。
4. **现场三步闭环实物演示（约 5 分钟）**
   - **演示一**：观察 UNO 板载 12×8 LED 点阵无闪烁轮播笑脸、温湿度、光照与暗光 `Zzz` 动画，通过交小西语音提问当前寝室环境并听取 `zh-CN-XiaoyiNeural` 声线播报。
   - **演示二**：遮挡光敏电阻或吹气改变温湿度，验证实时遥测链路与断电 35 秒后的 `unavailable` 过期保护。
   - **演示三**：在交小西网页端发起空调遥控器按键学习，演示 280 边沿波形捕获、前后状态防呆校验与挑战码单次回放。
