# 交小西 DormSense 答辩设计记录

本版按用户指定的 [2021simpleblue 模板](../assets/2021simpleblue.pptx) 制作，交付可编辑 PPTX、PDF、离线网页、逐页讲稿和 LED 素材。主线 18 页、答疑附录 2 页，建议总时长 14 分 15 秒，含 4 分钟实物演示。

## 视觉方向

沿用模板原有的校园照片、校徽、蓝色切面、目录和正文标题标识。封面与结尾保留原模板对象，内容页使用原模板的正文布局；流程图、表格、数字和文字均由可编辑对象组成。

配色为白色 #FFFFFF、正文深蓝 #182B3B、主蓝 #005AA6、青蓝 #039ACF、点阵亮色 #89DFFD、次级文字 #647584 与浅底 #EAF3FA。中文使用微软雅黑，英文和数值使用 Arial。画布为 1600×900、16:9，正文标题 60 px，主要内容通常 29–36 px。

内容页根据表达对象分别采用比较表、横向流程、点阵大图、状态并列、趋势曲线、预算明细和责任行。连接线表达消息或数据的实际方向。原模板的照片、蓝色图形及其效果随模板保留。

最初曾用 design-taste-frontend 抽取 sentence-as-layout，seed 20261106；用户随后明确指定校级蓝色模板，本版据此调整视觉。设计的核心对象仍是 UNO 的 12×8 点阵，放大其固件真实像素，让状态展示成为答辩中的主要视觉。

## 项目对象与内容证据

本项目的具体对象包括：96 个 LED 像素、每幕 6 秒的轮播、暗光困倦表情、700 ms 长按与松手发送、UART 字节流、MQTT 发布订阅、35 秒过期、24 小时历史、一维卡尔曼、280 项长帧案例、300 项导出容量、14 字段状态比对和 57.64 元新增采购。

| 内容 | 材料与表达方式 |
| --- | --- |
| 商业智能音箱对比 | DuerOS 官方接入与技能平台文档；比较定位、设备接入、环境数据与开发方式 |
| 硬件与供电 | 两套固件与硬件说明；分别标出环境节点和红外节点、共地供电支路 |
| MQTT 基础 | 发布者 → Broker → 订阅者，结合实际 Topic 说明发布订阅 |
| 项目消息链路 | 原始遥测 → validator → 校验主题 → HA 实体，列出四类主题和可靠性设置 |
| LED 动画 | 主机程序包含原固件头文件，导出九类状态；示例输入与帧摘要随素材保存 |
| 语音与工具调用 | Hermes 补丁、工作区说明和只读网关；标出模型发起调用、Hermes 执行、数据返回模型再回答 |
| 历史与滤波 | 三路独立的一维卡尔曼；曲线标注为合成数据示意 |
| 红外学习 | 建立基线、逐键学习、14 字段比对、本地确认回放与现场观察 |
| 采购与协作 | 公开元数据保存五项采购与六人分组，重建时直接读取 |

5. 两块开发板，分开处理感知和红外，45 秒。
6. MQTT：无线节点怎样交换消息，55 秒。
7. MQTT 在项目里的实际走向，50 秒。

9. 从表情里，看出当前状态，30 秒。

11. 工具怎样读到宿舍的实时数据，35 秒。

13. 空调红外：从原始波形开始学习，50 秒。
14. 三处联调，真正把器件接起来，40 秒。
15. 五项新增采购，共 57.64 元，25 秒。

17. 实物演示：从遮光，到一句回答，240 秒。
18. 谢谢大家，15 秒。
19. 附录：关键参数速查，答疑时使用。
20. 附录：源码与参考资料，答疑时使用。

逐页文案、布局和讲稿集中在 [内容定义](../src/content.py)，备注、网页与讲稿同步生成。第 8 页嵌入 GIF，网页同时提供状态切换、暂停和逐帧；减少动态效果设置下默认暂停。

## 制作检查

使用 LibreOffice 将实际 PPTX 导出为 PDF，再渲染全部 20 页进行检查。第一轮修正目录英文标题、工具框孤字换行和点阵图注间距，第二轮核对修正结果。结构检查核对页面数、备注、包内关系、采购金额、原模板摘要、像素尺寸、GIF 和素材引用；结果记录在 [制作与验收说明](../验收说明.md)。
