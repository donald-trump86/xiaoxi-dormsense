# 硬件清单与已确认接线

本页区分已接入器件、备用物料和待现场验收。下列接线来自既有实现与实物记录；2026-11-05 的源码整理没有重新烧录、操作串口或测试空调。不要将本页套用于不同型号模块。

## 当前节点

| 节点 | 已确认硬件 | 固件基线 |
| --- | --- | --- |
| node01 | Arduino UNO R4 WiFi、SHT31 UART 模块、LM393 光敏模块、板载 12×8 矩阵、三线按钮 | [UNO 项目](../firmware/arduino-uno-r4/README.md)，Renesas 平台 1.9.0 / 核心 1.6.0 / PubSubClient 2.8.0 |
| node02 | ESP32-C3、三针红外发射模块、三针红外接收模块 | [C3 项目](../firmware/esp32-c3-ir/README.md)，Espressif 平台 6.9.0 / Arduino ESP32 2.0.17 / IRremoteESP8266 2.9.0 |

C3 芯片曾核实为 QFN32、revision v0.4、4 MB Flash；`esp32-c3-devkitm-1` 是所用编译目标，不据此推断开发板品牌。UNO R4 WiFi 不等于 UNO R3、UNO WiFi Rev2 或普通 ESP32；其板载网络协处理器也不是独立的 node02。

## UNO 感知与反馈

| 通道 | 已确认连接 / 行为 | 限制 |
| --- | --- | --- |
| SHT31 UART 模块 | 模块 TXD → UNO D0 / Serial1 RX；模块 RXD 不接，公共 GND；9600 baud、8N1，约 1 Hz ASCII 帧 | 当前模块不是裸 SHT31 I²C 驱动，不猜 0x44/0x45 地址。模块额定供电以实物核实为准 |
| LM393 光敏模块 | VCC → 5V，GND → GND，AO → A0，DO 不接 | 10 bit ADC，归一化约为 `(1023 - adc) / 1023`；0 暗、1 亮，没有 lux 标定 |
| 12×8 LED 矩阵 | 使用板载矩阵与官方库 | 温度计、水滴、灯泡、表情和状态动画；场景不是额外传感器 |
| 三线按钮 | 保持已确认的 D2 / D3 / D4 三端接法，源码扫描六个有向引脚对并建立基线 | 未标注三端不能随意当成 VCC/GND/OUT。观察到单击事件，最新源码对应二进制及双击/长按尚待现场核对 |

光敏模块的 PWR LED 表示供电，通常一直亮；DO LED 对应比较器阈值，电位器调整它的切换点，不会把 AO 自动归零。UNO 矩阵扫描与 A0 的引脚配置共享底层寄存器，固件保留采样期间短暂暂停扫描及恢复 PFS 写访问的修复，不应在未验证时删除。

温湿度和光照都只有功能性读取与链路验证，没有参考仪器校准。当前值、缺测和未同步时间的 MQTT 语义见[协议](mqtt-protocol.md)。

## C3 红外收发

| 模块端子 | C3 连接 |
| --- | --- |
| 接收 VCC | 3V3，保持输出为 3.3 V 逻辑 |
| 接收 GND | GND |
| 接收 OUT | IO4 |
| 发射 VCC | 按已确认发射模块额定供电，沿用现有 5V/3V3 接法 |
| 发射 GND | GND |
| 发射 DAT | IO3，3.3 V 控制逻辑 |

这里使用带驱动的发射模块，不用 GPIO 直接驱动裸红外管。载波为约 38 kHz；射频模块或火焰传感器不能替代解调式红外接收模块。

实际遥控器曾被解码为 GREE/KELVINATOR，当前发送使用库构造完整状态。不能把一段收到的“开机”状态直接当成所请求的“制冷 26°C 自动风”状态。预览不发射；真实 `sendAc()` 分支只调用一次选中协议，库内部仍可能生成协议要求的多帧或重复帧。

C3 上电校准会输出载波，首次 MQTT 连接后的 NEC 回环自检也会发射。固件没有本地 disarm 开关，命令解析、TTL 年龄和持久去重仍有限制，见[C3 说明](../firmware/esp32-c3-ir/README.md)。节点发送回执、接收端本地回波和空调实际响应是三类不同证据；现有记录不能代替空调状态反馈。

## 供电与无线运行

刷好固件并保留正确配置后，板子不需要 Mac USB 数据连接才能运行。现有单线供电方案是 USB 给 UNO 供电，再用 UNO 5V/GND 给 C3 的 5V/GND 供电；不能把 5V 接入 C3 的 3V3 引脚。接线前断电，供电容量、线损与模块兼容性按实物核对，本次没有测量电流或纹波。

Wi-Fi、Broker 地址和证书名称仍须匹配，承载 MQTT/HA/Hermes 的主机也须保持可用。目前这些服务在 Mac 上，板子有电不代表服务器同时在线；换网络或 Broker IP 后需要重新核对路由、证书和配置。

## 备用与未接入物料

| 类别 | 已有 / 既有清单物料 | 当前状态 |
| --- | --- | --- |
| 温度备选 | DS18B20、TMP36/LM35 类模块 | 未接入当前数据链；型号、电平、上拉或量程仍需核实 |
| 输入 | 电位器、旋转编码器、PS2 摇杆、其他轻触开关 | 不属于已验收输入通道 |
| 提示输出 | 有源/无源蜂鸣器、RGB/双色 LED | 未纳入当前可控实体 |
| 配件 | 面包板、杜邦线、USB 数据线、万用表、电阻包 | 接线、限流与电流预算按实际器件核对 |
| 其他 | 声音、超声波、火焰、雨滴、震动、霍尔、光电等套件器件 | 型号及用途未确认，不写成已接入传感器 |

继电器、市电、门锁和加热负载不接入本项目。后续新增通道先确认器件、数据手册、供电、引脚、库版本和测试方法，再同步 Schema、固件、HA、网关与测试。
