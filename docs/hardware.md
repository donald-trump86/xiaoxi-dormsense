## 空调控制链路

| 器件 | 状态 | 作用 |
| --- | --- | --- |
| 红外遥控器（宿舍原装） | 已拥有 | 录制空调原始码 |
| 泽杰 1838 红外接收头（VS1838B 类） | 已购 | 38 kHz 载波解调，接收遥控器时序 |
| 红外发射管（5 mm 940 nm） | 已购 | 发射控制码 |

射频与红外是两套不同机制，不可互相替代：433/315 MHz 射频模组用于无线开关、门铃一类设备，空调接收端没有射频天线，对它发射不会生效；38 kHz 红外才是空调遥控的常见方式。火焰传感器只检测火焰自发辐射的宽谱红外，不含载波解调通路，**不能替代红外接收头**。

空调遥控发送的是完整状态帧而非单键短码，固件需注意：使用 raw 录制模式而非协议解码模式；`IRremote` 默认的 `RAW_BUFFER_LENGTH`（200）对空调长帧远远不足，必须显著调大并实测能容纳完整帧；同一按键连录数帧比对一致后再重放，并连尾部状态位一并还原。此链路是 38 kHz 红外发射，**不涉及市电**；宿舍空调属共用设备，接线与使用须先经教师确认。

## 未纳入本阶段方案

声光与存在类外围器件（超声波、声音、火焰、雨滴、震动、干簧管、模拟霍尔、U 型光电、倾斜开关、激光、触摸开关）不列入本期方案。执行器与市电负载（继电器等）不接入，空调控制一律走红外。

## 推荐开发基线

Arduino IDE 2.x，Boards Manager 安装官方 UNO R4 Boards 并选择 UNO R4 WiFi。先运行官方最小串口/LED 矩阵示例，记录 OS、IDE、核心包、USB端口与实际烧录结果；再测试一个真实传感器。Arduino CLI/PlatformIO 自动编译暂不作为 CI 条件，等库和核心版本明确后增补，不把未经验证的编译配置当成可用。

固件建议分为 config、sensor sampling、filter、mqtt transport、status indicator；非阻塞定时采样、简单均值或中值滤波、网络退避重连。失效数据为 null，不要人为制造正常值。Wi-Fi/MQTT 密钥放本地 `secrets.h`（已忽略），公共头文件只保留接口与配置占位。
