| 项目 | 状态 | 本阶段动作 |
| --- | --- | --- |
| Arduino UNO R4 WiFi | 已拥有 | 记录板卡版本、端口、核心包版本，完成官方基础示例 |
| 部分配套传感器 | 已拥有但型号/接口未确认 | B 拍摄型号标签，查原厂数据手册并与 A 核实 |

| 执行器/电源/其他配件 | 未确认 | 不接市电、门锁、加热器等高风险负载 |

UNO R4 WiFi 不应被当成 UNO R3、UNO WiFi Rev2 或通用 ESP32 板；使用其官方板卡核心和适配的 WiFiS3 能力，不凭名字套用其他板引脚/库。板上网络协处理器也不等于已拥有可单独部署的 ESP32 节点。

## 推荐开发基线

Arduino IDE 2.x，Boards Manager 安装官方 UNO R4 Boards 并选择 UNO R4 WiFi。先运行官方最小串口/LED 矩阵示例，记录 OS、IDE、核心包、USB端口与实际烧录结果；再测试一个真实传感器。Arduino CLI/PlatformIO 自动编译暂不作为 CI 条件，等库和核心版本明确后由 B/A 增补，不把未经验证的编译配置当成可用。

固件建议分为 config、sensor sampling、filter、mqtt transport、status indicator；非阻塞定时采样、简单均值或中值滤波、网络退避重连。失效数据为 null，不要人为制造正常值。Wi-Fi/MQTT 密钥放本地 `secrets.h`（已忽略），公共头文件只保留接口与配置占位。
