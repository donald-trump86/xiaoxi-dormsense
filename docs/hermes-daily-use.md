# Hermes 日常使用与逐键学习

2026-11-05：当前实验实例已应用精简配置，并更新现有 `http://127.0.0.1:9119` 网页构建。正式镜像的构建配方与实验实例仍须分别验收。此文说明已实现的行为；登录后的真实浏览器操作、原装遥控器逐键实录及空调响应尚未验收。

## 保留的能力

- 查询宿舍当前传感器状态，继续经过固定实体的 HA 只读网关。
- 原装空调遥控器逐键学习、状态核对和私有档案保存。
- 既有 Whisper 语音输入、Edge 语音输出。
- 原生记忆、用户偏好、历史会话检索和上下文压缩。

通过官方设置关闭 A2A、Spotify 插件和看板自动通知/调度。CLI 工具选择为 `homeassistant`、`xiaoxi_ir_learning`、`memory`、`session_search`；延迟工具发现所需的 `tool_search`、`tool_describe`、`tool_call` 仍保留。未删除旧聊天、账号或任务。可合并的配置见[日常助手片段](../hermes/config.dorm-assistant.yaml)。

Home Assistant 的独立消息平台已停用：它需要 WebSocket 订阅事件，与当前固定实体的 REST 只读查询用途不同。保留 `HASS_URL`、`HASS_TOKEN` 和 `homeassistant` 查询工具。仪表盘“连接的平台”中该消息适配器的重连失败，不代表温湿度查询失败；查询是否可用应以实际工具调用为准。

## 默认继续日常会话

1. 刷新现有 9119 页面。为明确使用新工具配置，建议本次更新后先新建一次日常会话，再发送第一条消息。
2. 此后在同一浏览器、同一网页部署路径、同一 Hermes profile 下进入聊天页，会优先继续上次确认存在的会话。网页保存真实数据库会话 ID，不按“最近一条”选择测试对话。
3. 显式选择历史聊天时，继续你选中的会话；点击“新建会话”时，保留新建意图。空白草稿只有发送消息并确认数据库记录存在后，才可成为下次恢复的对象。
4. 不同 profile、部署路径和浏览器分别记录选择。禁用或清空浏览器本地存储后，需要重新选择会话；这不会删除 Hermes 中的聊天。

网页会先核对会话及当前后继会话，再连接终端。已删除的会话会清除本地选择；临时后端故障保留恢复意图。这里使用项目网页补丁；原生 TUI 的自动恢复最近会话保持关闭，避免覆盖显式新建操作。

## 同一会话和长期记忆的区别

| 机制 | 用途 | 边界 |
| --- | --- | --- |
| 当前会话上下文 | 延续正在讨论的事 | 模型上下文有限，不会永远携带全部原文 |
| 上下文压缩 | 对话很长时整理旧内容 | 摘要可能省略细节，不等于逐字保存 |
| 原生记忆/用户档案 | 保留重要偏好和稳定事实 | 当前限额仍为 2200/1375 字符，未扩大 |
| `session_search` | 需要时检索旧聊天 | 按需找回相关内容，不是每轮自动读取全部历史 |

继续一个日常会话有助于保持话题连贯，但不会获得无限记忆。重要约定可明确说“记住……”，以后仍可核对或修正。温湿度、在线状态等易变信息必须重新查询，不能把旧聊天当作当前读数。

当前已关闭 `sessions.auto_prune`，保留旧聊天；数据库会随使用增长，后续可由用户主动管理历史。

## 开始录制遥控器

C3 已完成本轮唯一一次通用固件更新，`learn1` 在线状态已核对。默认启动被动接收，不再自动发校准载波或 NEC 自检。现阶段不需要再烧录。

准备好原装遥控器，将它对准 C3 接收头，并避开空调的接收窗口。在日常会话中说：

> 初始化空调，逐个教常用按键。每次只开一个接收窗口，等我按完并确认后再继续。

先说明遥控器屏幕上的开关、模式、设定温度和风速，再按提示建立第一份接收基线。基线以实际收到的按键后状态为准，不预设某个按钮不会改变状态。

推荐先录这些实际存在的键，每次只按一次：

1. 电源开关。
2. 模式。
3. 温度＋。
4. 温度－。
5. 风速。
6. 上下扫风。

随后按需补录左右扫风、灯光、睡眠、超强、干燥/自清洁、节能等键。服务确认接收就绪后，窗口为 45 秒；超时或中途改变遥控器状态，需要重新建立基线。

已知状态会核对按前/按后变化；按错键或预期字段未变时，不自动绑定。未识别或库不支持的功能需要你提供明确名称，保存时仍标为人工说明、未验证。遥控器常发送完整设定状态，因此同一个键可以有多份不同状态样本，不能把一份波形当作任意状态下的通用增量命令。

原始波形和档案保存在学习服务私有卷中，聊天工具只返回受限摘要。录制不会让 C3 自动回放。真实回放使用独立的可信操作者流程，并需要对某一次动作明确授权；发送回执也不证明空调已响应。详细边界见[学习服务](../services/ir_learning/README.md)和[空调接入说明](ac-onboarding.md)。
