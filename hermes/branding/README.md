# 交小西网页端品牌资源（`hermes/branding`）

本目录存放由 [hermes/apply_patch.py](../apply_patch.py) 与 [hermes/Dockerfile](../Dockerfile) 自动部署到 Hermes Web 前端的交小西项目视觉资产（派生自 [presentation/dormsense-intro/images/xiaoxi-dormsense-logo.png](../../presentation/dormsense-intro/images/xiaoxi-dormsense-logo.png)）：

- [manifest.json](manifest.json)：品牌资源文件清单与 SHA-256 校验值。
- [xiaoxi-logo.png](xiaoxi-logo.png)：顶部导航栏与状态页使用的 `256×256` 圆形透明背景徽标。
- [xiaoxi-login.png](xiaoxi-login.png)：Web 登录门禁页（`LoginGate`）使用的 `512×512` 交小西主题插画。
- [apple-touch-icon.png](apple-touch-icon.png) 与 [favicon.ico](favicon.ico)：浏览器标签页与移动端主屏幕图标。
