# 数据治理

- `samples/telemetry.simulated.json` 是人工构造的协议样例，`simulated=true`，不是实际测量。
- `raw/`（运行时创建、Git忽略）存真实原始数据；追加不覆盖，记录接收时间/代码版本/实验编号。
- `processed/` 的运行输出默认忽略，仅目录说明可提交。

真实宿舍数据即使不含姓名，也可能推断在室时间和生活规律。默认本机保存、最小采集、参与者知情与授权、有限保留；公开前由负责人脱敏审查。不得把整个数据库或未经同意的数据上传 LLM。

模拟、真实、回放与插值需分别标记，回放不得冒充当前状态。正式实验元信息和评价方法见[实验方案](../docs/experiments.md)。
